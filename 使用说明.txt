大肥鱼启动器（桌面版）
=====================================

一个正经的窗口程序：双击「大肥鱼启动器.exe」就能用，
不用开黑窗口、不用敲命令。

一、怎么用
1. 双击 大肥鱼启动器.exe（想放到桌面就右键 → 发送到 → 桌面快捷方式，和普通程序一样）。
2. 第一次打开会花一两秒自动找 QQ、SnowLuma、wb2api、AstrBot 在哪里。
3. 点底部天蓝色的【启动】：按 QQ → wb2api → SnowLuma → AstrBot 的顺序拉起，
   每一步的日志会实时出现在右边的「运行日志」里。
4. QQ 第一次要扫码登录；登录后 SnowLuma 会自动挂上，卡片上的端口会变成「开」。
5. 关窗口只是关界面，机器人还在跑；要停机器人点【停止】
   （默认不关 QQ，关了你的号会掉线）。

二、界面上的东西
- 顶部：看板娘 + 程序名，右上角是最小化 / 关闭，按住标题栏可以拖动窗口。
- QQ 登录横幅：显示「已登录（QQ 号）/ 未登录 / QQ 没开」，颜色跟着状态变。
- 左边四张卡片：QQ 客户端、wb2api、SnowLuma、AstrBot。
  右上角是运行状态，下面一行是进程和端口；双击卡片可以打开对应的网址。
- 右边深色卡片：运行日志，最多保留最近 1500 行，会自动滚动。
- 底部按钮：启动 / 停止 / 重启 / 打开面板 / 日志。

三、路径设置
程序会自动找 QQ 和三个程序文件夹，一般不用管。
程序识别到的位置会自动填进设置里、也写进 config.ini，不用你手动抄。
发现哪个不对，就点窗口右上角的齿轮（最小化按钮左边）改一下，点【保存】；
把某一项清空 = 这一项重新自动查找。
也可以直接改文件夹里的 config.ini，内容就是这四项：QQPath / AstrBotDir / SnowLumaDir / Wb2apiDir。
支持相对路径，比如 ..\SnowLuma-v2.2.1-win-x64；改完关掉程序重开。

自动查找会看：注册表里的安装信息、资源管理器里留下的历史路径、
常见安装位置、各磁盘根目录，最后再浅扫一遍。
三个程序文件夹和本程序放在同一层（或上一级）时，一般不用改。

四、图标和界面
图标和头像是「蓝色大肥鱼」的立绘，已经编译进 exe 里，
所以只有一个 exe 也能正确显示文件图标、任务栏图标和窗口里的头像。
窗口里的渐变、上浮的水泡、卡片、按钮都是自己画的，没有用第三方界面库。

五、分享给别人时要特别注意
- 只发这个文件夹里的 exe / 说明 / 源码，不要顺手带上：
  SnowLuma\config（里面有面板密码哈希和 accessToken）
  SnowLuma\data（聊天记录）
  logs（日志里可能有 QQ 号和聊天片段）
  C:\Users\<你的用户名>\.astrbot（机器人配置和模型 key）
- 别人第一次用要扫码登录他们自己的机器人号。

六、文件夹里的其它东西
- config.ini：设置里保存的路径就存在这里，也可以直接改（留空 = 自动找）。
- 除了 config.ini 没有别的配置文件；启动、停止、重启都在窗口里点按钮。
- 开发 文件夹：只有想改程序时才用得到。
    build.ps1        重新编译（用 Windows 自带的编译器，不用装 .NET SDK）
    source           界面和逻辑的源码
    tools\make-icon.ps1  换图标：给它一张图，自动生成 app.ico 和 WhaleAvatar.png
    boot.ps1         最早的 PowerShell 版本，留作备用

七、常见问题
Q：点了启动没反应？
A：看右边日志。如果提示没找到 AstrBot，点右上角齿轮把目录选上，保存即可。

Q：SnowLuma 一直显示未运行？
A：它要等 QQ 登录后才会挂上。QQ 停在登录界面时，日志里会先出现 awaiting login，
   扫码进去以后会自己连上。

Q：面板打不开？
A：先看 SnowLuma 卡片上的端口是不是「开」，再点【打开面板】。
   5099 被占用时会自动换成 5100，卡片上显示的是真实端口。

Q：启动很久还没好？
A：第一次启动 AstrBot 要加载 Python 运行环境，十几秒是正常的，日志会一直刷新。
